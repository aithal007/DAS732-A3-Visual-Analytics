# A3 video: 6-minute shot-by-shot script

Total **5:55** (speech at 150 words per minute, plus slide changes, app switches and clicks). Generated by `src/build_slides_6min.py`; the same text is in the speaker notes of `slides/DAS732_A3_DataStory_6min.pptx`.

## Before recording (5 minutes)

1. Start the app locally, in a terminal:
   ```
   cd ass3/A3_submission
   streamlit run app.py
   ```
   It opens **http://localhost:8501**. Backup if it fails: the live copy at https://aithal007.github.io/DAS732-A3-Visual-Analytics/ (first load 20-60 s).
2. In the browser: click the **Workflow** tab, scroll to the top, sidebar *Focus country* = **India**, *Model views show* = **Iteration 2**. Zoom the browser to 90% so whole charts fit.
3. Open `slides/DAS732_A3_DataStory_6min.pptx` in **Slide Show** (F5) on slide 1. Hidden slides 17-24 are skipped automatically; keep them for questions.
4. Only two windows open: PowerPoint and the browser. **Alt+Tab** switches between them.
5. Record the whole screen with audio: OBS Studio (Display Capture + microphone), or a Teams/Zoom meeting with screen share and Record. One person shares and clicks; each speaker unmutes for their part.
6. Rehearse once with a timer. If you run long, drop a click, not a sentence.
